PinPoint

Real-time delivery tracking with live location sharing, ETA updates and arrival visibility. Deliberately built with vanilla HTML, CSS and JavaScript so it stays fast, light and easy to understand.

Visit site ↗
HTML CSS JavaScript Firebase Realtime DB Maps API

Context

Delivery work is a visibility problem: customers want to know where their order is, operators want fewer support calls, and drivers need an interface that stays light while updating location in near real time.

What I built

The location-sharing flow, ETA updates, a dispatch-friendly dashboard, and a live map experience that shows movement without forcing users through a heavy mobile app. Firebase Realtime Database provides the low-latency sync and the Maps API gives the live geographic context.

Why this approach

Firebase Realtime DB fits the need for low-latency sync, and the frontend stayed deliberately simple so the product feels fast and is easy to extend. Status clarity first, decoration second.

Role & scope

The tracking flow, the map UI, and the operational experience for both dispatchers and recipients.

Result

A live tracking engine that cut ping latency between drivers and customers and shows delivery movement in near real time—no framework bloat.
